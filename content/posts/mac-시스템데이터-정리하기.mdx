맥을 쓰다 보면 저장공간이 금방 차는데 그중 시스템 데이터가 엄청 커지는 경우가 있습니다. 전 총 256gb ssd를 사용중인데 시스템 데이터가 제 경우엔 **무려 135.5GB**까지 불어난 상태였습니다.
이게 맥은 시스템 데이터를 정리하고자 해도 얼마나 차지하는지 표시만 할 뿐 어디서 삭제해야하는지를 안내를 안해줍니다. 저는 iCloud도 꺼져 있고, 캐시 정리도 했는데 줄지 않는 상황이었습니다. 클램셀모드로 사용중이라 스냅샵 문제도 살펴봤지만 이 파일들은 아예 존재하지도 않았습니다.

결론부터 말하면, Finder로는 보이지 않는 **숨은 캐시들**이 원인이었습니다. 이걸 직접 파일을 찾아 지워줬는데요.

---

## 📌 문제 상황 요약

- 시스템 데이터가 **135.5GB**로 비정상적으로 큼
- iCloud Drive OFF
- Time Machine 스냅샷 없음
- 브라우저/앱 캐시 정리했지만 변화 없음

이것저것 시도해보고 안쓰는 파일들을 정리해도 해결을 못하다가 도무지 원인을 모르겠어서,
응용프로그램 제거로 제거했지만 아직 데이터는 남아있다거나 알수없는 캐시들이 원인인가 생각했습니다.
그래서 뭐가 이렇게 큰 용량을 차지하는거지란 생각에 터미널에서 데이터 용량순으로 정렬한 다음 직접 큰 크기의 파일부터 살펴보기로 했습니다.

---

## 🔍 어디가 이렇게 큰가?

아래 명령어를 활용했는데요.

> `sudo du -sh /Users/*`
>
> - **sudo**: 관리자 권한으로 실행
> - **du**: 디스크 사용량 확인(disk usage)
> - **-s**: 각 폴더의 총합만 요약(summary)
> - **-h**: 사람이 읽기 쉬운 단위(G, M, K)로 표시

먼저 사용자 폴더(Users)부터 확인했습니다.

```bash
sudo du -sh /Users/*
```

결과는 `/Users/내계정명`이 103GB이었습니다. 여기서 Library 폴더부터 검사해보기로 했습니다.

---

## 🔍 Library 내부 스캔

> `|` (pipe)
>
> - 앞 명령어의 **출력(output)** 을  
>   뒤 명령어의 **입력(input)** 으로 전달
> - `| sort -hr`: 결과를 **용량 기준으로 내림차순 정렬**

```bash
sudo du -sh ~/Library/* | sort -hr
```

이 결과가 바로

```bash
39G    Containers/com.apple.mediaanalysisd
20G    Caches
15G    Developer
...
```

정리하자면,

- **mediaanalysisd(39GB)** → macOS가 사진/영상 인식 과정에서 만든 캐시가 폭주한 것
- **Caches(20GB)** → 앱 캐시들이 오래 쌓인 것, 말 그대로 앱들의 캐시
- **Developer(15GB)** → xcode 관련 파일들

캐시 관련 폴더 둘이 합쳐서 거의 60GB를 잡아먹고 있었습니다. 아니 mediaanalysisd이 도대체 뭐길래 이렇게 차지할까 검색해보니 Media Analysis Daemon이라고 사진 앱에서 사람 얼굴 인식, 사진/스크린샷의 텍스트(OCR) 인식
등 이런 일을 한다고 합니다. 근데 이렇게 캐시가 쌓이는건 대부분이 버그라고합니다...

---

## 🗑️ 삭제하기

### 1) mediaanalysisd 폴더 삭제 (가장 큰 범인)

> `rm -rf ~/Library/Containers/com.apple.mediaanalysisd`
>
> - **rm**: 파일 또는 폴더 삭제
> - **-r**: 내부 하위 폴더까지 재귀적으로 삭제
> - **-f**: 확인 없이 강제로 삭제(force)

```bash
rm -rf ~/Library/Containers/com.apple.mediaanalysisd
```

삭제해도 문제 없습니다. 필요하면 macOS가 자동으로 다시 생성합니다.

→ 약 **38GB 감소**

---

### 2) Caches 폴더 정리

폴더 자체는 삭제하면 안 되고, **안의 내용만 통으로 비우면 됩니다.** 이 폴더도 그냥 앱들의 캐시들입니다. 예를들어 웹 브라우저 캐시들도 다 지워지니 필요하다면 주의하세요.

```bash
rm -rf ~/Library/Caches/*
```

→ 약 **10~15GB 감소**

---

### 3) 개발자 관련 데이터 정리

Xcode나 시뮬레이터를 사용했다면 아래 경로도 꽤 큽니다.

```bash
rm -rf ~/Library/Developer/CoreSimulator
```

예전 xcode로 앱 개발시에 시뮬레이터를 종류별로 많이 깔았는데 xcode를 지워도 이게 같이 안지워집니다... 필요 없는 시뮬레이터 장비들이 수 GB씩 쌓여 있을 수 있어, 통째로 삭제해도 문제 없습니다.

→ 약 **15GB 감소**

## 🧭 전체 명령어 정리

```bash
# Library 용량 확인
sudo du -sh ~/Library/* | sort -hr

# mediaanalysisd 삭제
rm -rf ~/Library/Containers/com.apple.mediaanalysisd

# Caches 비우기
rm -rf ~/Library/Caches/*

# 사용하지 않는 iOS 시뮬레이터 삭제 (옵션)
rm -rf ~/Library/Developer/CoreSimulator
```
