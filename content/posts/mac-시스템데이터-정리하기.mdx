맥을 쓰다 보면 저장공간이 금방 차는데, 시스템 데이터가 비정상적으로 커지는 경우가 있다. 256GB SSD를 사용 중이었는데 시스템 데이터가 **135.5GB**까지 불어난 상황이었다.

맥은 시스템 데이터 용량은 표시해줘도 어디서 어떻게 삭제해야 하는지는 안내하지 않는다. iCloud는 꺼져 있고, 캐시 정리도 했고, 스냅샷 문제도 확인했지만 변화가 없었다.

결국 원인은 Finder로 보이지 않는 **숨은 캐시**였다.

---

## 문제 상황

- 시스템 데이터: **135.5GB** (비정상)
- iCloud Drive: OFF
- Time Machine 스냅샷: 없음
- 브라우저/앱 캐시 정리: 효과 없음

---

## 원인 파악: 터미널에서 용량 추적

```bash
sudo du -sh /Users/*
```

- `sudo`: 관리자 권한으로 실행
- `du -s`: 각 폴더의 총합만 요약(summary)
- `-h`: 사람이 읽기 쉬운 단위(G, M, K)로 표시

결과: `/Users/계정명`이 103GB. Library 폴더를 상세 확인했다.

```bash
sudo du -sh ~/Library/* | sort -hr
```

`| sort -hr`: 결과를 용량 기준 내림차순 정렬.

결과:

```bash
39G    Containers/com.apple.mediaanalysisd
20G    Caches
15G    Developer
...
```

- **mediaanalysisd (39GB):** macOS 사진/영상 인식(OCR, 얼굴 인식) 과정에서 생성된 캐시. 대부분 버그로 인한 비정상적 누적이다.
- **Caches (20GB):** 앱 캐시 누적.
- **Developer (15GB):** Xcode 관련 파일.

---

## 삭제

### 1) mediaanalysisd 삭제 (주요 원인)

```bash
rm -rf ~/Library/Containers/com.apple.mediaanalysisd
```

삭제해도 무방하다. macOS가 필요 시 자동으로 다시 생성한다.

→ 약 **38GB 감소**

---

### 2) Caches 비우기

폴더 자체는 삭제하지 않고 내용만 비운다. 브라우저 캐시도 포함되므로 필요한 것이 있다면 확인 후 진행한다.

```bash
rm -rf ~/Library/Caches/*
```

→ 약 **10~15GB 감소**

---

### 3) iOS 시뮬레이터 삭제 (선택)

Xcode로 앱 개발 시 설치한 시뮬레이터가 Xcode 삭제 후에도 남아있다. 필요 없는 경우 삭제한다.

```bash
rm -rf ~/Library/Developer/CoreSimulator
```

→ 약 **15GB 감소**

## 전체 명령어 정리

```bash
# Library 용량 확인
sudo du -sh ~/Library/* | sort -hr

# mediaanalysisd 삭제
rm -rf ~/Library/Containers/com.apple.mediaanalysisd

# Caches 비우기
rm -rf ~/Library/Caches/*

# iOS 시뮬레이터 삭제 (선택)
rm -rf ~/Library/Developer/CoreSimulator
```
