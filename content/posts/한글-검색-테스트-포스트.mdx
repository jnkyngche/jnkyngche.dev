# 한글 검색 테스트 포스트

이 포스트는 한글 검색 기능을 테스트하기 위해 작성되었습니다. 다양한 한글 내용과 초성 검색을 테스트해보세요.

## 🎯 테스트할 수 있는 검색어들

### 일반 한글 검색

- **안녕하세요** - 기본 인사말
- **반갑습니다** - 환영 인사
- **감사합니다** - 감사 표현

### 초성 검색 테스트

- **ㅇㄴㅎㅅㅇ** → 안녕하세요
- **ㅂㄱㅅㅂ** → 반갑습니다
- **ㄱㅅㅎㅂ** → 감사합니다
- **ㅎㄱㅇㄹ** → 한글 언어

### 복합 검색

- **프로그래밍** - 개발 관련
- **웹개발자** - 직업 관련
- **프론트엔드** - 기술 분야

## 🔍 검색 기능 설명

### 초성 검색이란?

한글의 자음만으로 검색하는 기능입니다. 예를 들어:

- `ㄱㄴㄷ` → 가나다, 강남동, 고려대 등
- `ㅍㄹㄴㅌㅇㄷ` → 프론트엔드
- `ㅇㅇㅇ` → 아아아, 어어어, 오오오 등

### 검색 우선순위

1. **제목 매칭** (100점) - 가장 높은 우선순위
2. **설명 매칭** (50점) - 메타데이터 설명
3. **내용 매칭** (10점) - 본문 내용

## 📝 다양한 한글 내용

### 기술 관련 용어

- **React.js** - 프론트엔드 프레임워크
- **TypeScript** - 타입 안전한 JavaScript
- **Next.js** - React 기반 프레임워크
- **Tailwind CSS** - 유틸리티 우선 CSS 프레임워크

### 일상 생활 용어

- **커피** - 아침에 마시는 음료
- **책상** - 공부하는 곳
- **컴퓨터** - 작업 도구
- **키보드** - 입력 장치

### 감정 표현

- **행복하다** - 기쁜 마음
- **슬프다** - 우는 마음
- **화나다** - 분노하는 마음
- **설레다** - 떨리는 마음

### 시나리오 1: 정확한 단어 검색

검색어: `프로그래밍`

- 제목에 포함되어 있어 높은 점수
- 내용에도 여러 번 등장

### 시나리오 2: 초성 검색

검색어: `ㅍㄹㄱㄹㅁ`

- `프로그래밍`과 매칭되어야 함
- 정규식 변환 테스트
